# สมุดจองล็อค

เว็บหน้าเดียวสำหรับบันทึกการจองล็อคขายของตามตลาดและงานเทศกาล หลายคนกรอกพร้อมกันได้ผ่าน Firebase

ลำดับใช้งาน: **งานเทศกาล → ผังโซนและเลขล็อค → แตะเลขล็อคเพื่อบันทึก** (ราคาปิดประมูล, ขายอะไร, ติดต่อ, สถานะ)

## ความสามารถ
- ตั้งชื่อโซนได้อิสระ (VIP, อาหาร, A ฯลฯ) ล็อคแสดงเป็น `ชื่อโซน-เลขล็อค` เช่น `VIP-001`
- สร้างโซนต่อเนื่องแบบเพิ่มต่อท้าย ข้ามชื่อที่มีอยู่แล้ว ไม่สร้างทับ
- ประเภทล็อค `$` ประมูล / `#` ตามลำดับ ตั้งเป็นค่าเริ่มต้นของโซน และแก้ทีละล็อคได้
- โซนย่อ/ขยายได้ ระบบจำสถานะที่ย่อไว้
- ดาว 1–5 ต่อล็อคเพื่อดูล็อคยอดฮิต มีแถบยอดฮิตและตัวกรอง
- ปักหมุดล็อคที่สนใจ มีแถบปักหมุดและตัวกรอง (ทีมเห็นหมุดเดียวกัน)
- ราคาเริ่มต้น ตั้งทั้งโซนได้ในหน้าแก้ไขงาน และแก้ทีละล็อคได้ในแผ่นบันทึก
- ดาว หมุด ราคาเริ่มต้น และประเภทล็อค เก็บเมื่อกด "บันทึก" เท่านั้น ปิดแผ่นโดยไม่บันทึกจะไม่เปลี่ยนอะไร
- รายการแสดงเป็นแถวเล็ก แตะแถวเพื่อแก้ไข แตะป้ายสถานะเพื่อเปลี่ยนสถานะ
- สำรอง/กู้คืน: บันทึกเป็นไฟล์ (Chrome บนคอมเลือกโฟลเดอร์ได้), แชร์ไป Drive/LINE/อีเมลบนมือถือ, คัดลอกเป็นข้อความ
- เปลี่ยนชื่อโซนที่มีรายการจองแล้ว รายการจองและดาวย้ายตามให้
- ไม่ต้องแก้ Rules เพิ่ม ดาวเก็บในเอกสารของงานเอง

## ตั้งค่า Firebase (ครั้งเดียว)
1. https://console.firebase.google.com → Add project
2. Build → Authentication → Sign-in method → เปิด **Anonymous**
3. Build → Firestore Database → Create database (โหมด production)
4. แท็บ Rules ของ Firestore → วางเนื้อหาจาก `firestore.rules` → Publish
5. ค่า config ของโปรเจกต์ใส่ไว้ใน `index.html` แล้ว (ตัวแปร `FIREBASE_CONFIG` ด้านบนสุด)
6. Authentication → Settings → Authorized domains → เพิ่มโดเมน GitHub Pages ของคุณ (`ชื่อ.github.io`)

## เปิดใช้งาน
- GitHub: Settings → Pages → Deploy from branch → main / root
- ถ้าเว็บเชื่อม Firebase ไม่ได้หรือไม่มีค่า config จะเก็บข้อมูลในเบราว์เซอร์เครื่องนั้นอย่างเดียว

## หมายเหตุความปลอดภัย
Rules ชุดนี้ให้ทุกคนที่เปิดเว็บเขียนข้อมูลได้ เหมาะกับลิงก์ที่แชร์กันในทีมเล็กๆ
ถ้าต้องการจำกัดเฉพาะบางคน ให้เปลี่ยนเป็นล็อกอินด้วยอีเมลหรือ Google แล้วกำหนดอีเมลที่อนุญาตใน Rules
